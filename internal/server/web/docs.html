PolyMC meta

Replace meta.polymc.org/v1/ or meta.prismlauncher.org/v1/ with {BASE}/meta/v1/:

ComponentSource
net.minecraftConverted from archived Mojang version JSONs; mainJar, assetIndex, libraries, compatibleJavaMajors and traits derived per version.
org.lwjgl3, org.lwjglGenerated from LWJGL entries in archived version JSONs; natives flatten into artifact-natives-{os} names.
net.minecraft.javaGenerated from archived Temurin manifests with sha256 checksums and Prism-style runtimeOS values.
net.fabricmc.*Generated from archived Fabric meta.

Components with no archived data are omitted from the index and return 404, or proxy to upstream meta when proxy_on_miss is on.

Integrity

Asset typeVerification
Jars, librariesMojang sha1 and size from the version JSON
Asset objectsSHA-1 carried in the URL path
Temurin archivesSHA-256 and size in the /java/temurin/{major} manifest

Clients should always verify. The mirror also verifies on serve for assets and Temurin; a corrupt object returns 404, or an upstream fetch when proxy_on_miss is on.

Checklist

  1. Set {BASE}; confirm public_url at GET /.
  2. Use returned URLs as-is; they are rewritten.
  3. Verify SHA-1 on game files, SHA-256 on Temurin.
  4. Support Range for large jars and resume.
  5. 404 means not archived on this mirror.
  6. Use /java/{v} and /java/temurin/{major} for auto-Java.
  7. For Fabric, swap the meta and maven hosts only.
  8. Apply aliases (1.5.0 to 1.5) on user input.
  9. GET and HEAD only.
